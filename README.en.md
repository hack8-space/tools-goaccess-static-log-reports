# GoAccess Static Log Reports

[Deutsch](README.md) | English

This project generates static GoAccess reports from web server access logs downloaded from a hosting provider via SFTP.

It was designed for static websites that do not need live analytics. A typical use case is an Astro website without login, server-side user accounts, or a dynamic application layer. If the provider only exposes access logs once per day, a daily cronjob is sufficient.

## Tested target environment

This project is tested on Debian/Ubuntu-based Linux servers with Docker, Docker Compose, bash, lftp, and Cron.

Other Linux distributions may work, but they are not actively tested.

## What happens?

1. The script lists available remote logs per domain via SFTP.
2. Missing local files are queued and downloaded provider-friendly in one SFTP session per domain.
3. Old local logs are optionally removed by filename date or mtime.
4. GoAccess runs briefly in Docker and generates one static `index.html` per domain.
5. A static landing page links to all domain reports.
6. nginx only serves the generated static HTML files.

## Provider-friendly defaults

```bash
SFTP_MAX_FILES_PER_RUN=25
SFTP_FILE_DELAY_SECONDS=2
SFTP_DOMAIN_DELAY_SECONDS=5
```

These values avoid aggressive backfills. During normal operation, usually only one new daily file per domain is downloaded.

## Example output

The project generates two static views:

1. a custom landing page linking to all configured domain reports
2. one regular GoAccess HTML report per domain

The actual report UI is generated by GoAccess. The landing page is generated by this script so multiple domain reports can be accessed from a single internal start page.

## GeoIP

GeoIP is intentionally not enabled by default in this project.

GoAccess can generate country or city statistics only if an additional GeoIP database such as MaxMind GeoLite2 or DB-IP is provided and mounted into the container. These databases have their own licensing, download, and update requirements.

This project is intentionally kept lightweight, so it does not ship a GeoIP database and does not set up automatic GeoIP updates. Also, some hosting providers anonymize IP addresses in web logs, which can make GeoIP results inaccurate or incomplete.

If you want GeoIP, you can add it manually later by mounting a suitable `.mmdb` file and setting `geoip-database` in the GoAccess configuration.
